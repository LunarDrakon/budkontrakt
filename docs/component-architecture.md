# Компонентна архітектура

## 1. Призначення застосунку

Застосунок розробляється для веб-сайту ремонтно-будівельної компанії. 
Основне призначення сайту — представити послуги компанії та надати 
користувачу інформацію про доступні види ремонтних і будівельних робіт.

## 2. Основні частини інтерфейсу

На початковому етапі застосунок містить головну сторінку, на якій 
відображається інформація про компанію та перелік її послуг.

Основними частинами інтерфейсу є:

- інформаційна частина головної сторінки;
- список послуг;
- картки окремих послуг;
- інформація про категорію, опис, ціну та доступність послуги.

## 3. Компонентна ієрархія

Початкова структура компонентів має такий вигляд:

App
└── HomePage
    ├── CompanyInfo
    ├── ServicesSection
    │   └── ServiceCard
    └── RequestSection

## 4. Відповідальність компонентів

### App

Кореневий компонент React-застосунку. Визначає основну структуру 
застосунку та підключає головну сторінку.

### HomePage

Головна сторінка веб-сайту ремонтно-будівельної компанії. Містить 
основну інформацію та перелік послуг.

### CompanyInfo

Компонент для відображення короткої інформації про ремонтно-будівельну 
компанію та напрямки її діяльності.

### ServicesSection

Компонент, який відповідає за відображення секції з послугами компанії.

### ServiceCard

Компонент для відображення інформації про одну послугу. Дані послуги 
передаються до компонента через props.

### RequestSection

Підготовлена секція для подальшого додавання можливості залишити заявку 
на виконання ремонтних або будівельних робіт.

## 5. Дані

Дані про послуги зберігаються окремо у файлі:

src/data/services.js

Це дозволяє не змішувати дані предметної області з кодом компонентів.

## 6. Основний принцип

Компоненти поділяються за відповідальністю. Компонент ServiceCard 
відповідає за відображення однієї послуги, а HomePage об'єднує основні 
частини головної сторінки.

Такий поділ дозволяє повторно використовувати компоненти та надалі 
розширювати застосунок без повного переписування вже створених частин.
## 7. Використання React Bootstrap

Для оформлення окремих елементів інтерфейсу використано бібліотеку
React Bootstrap. Зокрема, компонент Card використовується для
відображення окремої послуги в компоненті ServiceCard.

React Bootstrap використовується разом із власними CSS-стилями
проєкту. Це дозволяє використовувати готові компоненти бібліотеки
та одночасно зберігати власне оформлення сайту.

## 8. Повторне використання компонентів

Компонент Section використовується для різних секцій головної сторінки.
Він отримує заголовок через props та вміст через children.

Компонент ServiceList використовується для відображення списку
послуг, а ServiceCard відповідає за відображення окремої послуги.

Такий підхід дозволяє повторно використовувати компоненти та
спрощує подальше розширення веб-сайту.
